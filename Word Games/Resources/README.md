# Lab Resources & Specifications

This directory holds the authoritative assignment specifications and data files provided for the university Programming Lab.

## Contents

- `Word Games.pdf`: The authoritative university assignment brief covering the Trie data structure, dictionary specifications, and overview of word games.
- `dictionary.pdf`: Documentation regarding the dictionary word list and lexical parameters.
- `dictionary.txt`: The primary dictionary file containing 176,413 distinct English uppercase words (one word per line, ASCII letters A–Z).
